# NACo v3.0.0 Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `docs/superpowers/specs/2026-10-30-naco-v3-design.md` spec'ini uygulayarak NACo'yu tek sunuculu, FreeRADIUS önlü, SQLite tabanlı, güvenli ve test edilmiş v3.0.0 ürününe dönüştürmek.

**Architecture:** Eski kodun büyük kısmı yeniden yazılacağından, temiz bir temel üzerine aşamalı yeniden inşa: önce temel (config, DB, çekirdek yardımcılar), sonra saf mantık (politika, kimlik), sonra iç AAA API + FreeRADIUS, sonra yönetim API'si, TACACS+, portal, panel, dağıtım. Değerli eski parçalar `git show main:<yol>` ile alınıp taşınır.

**Tech Stack:** Python 3.12, FastAPI, Uvicorn, SQLAlchemy 2 (async) + aiosqlite, Alembic, Pydantic 2, bcrypt, cryptography (AES-GCM), pyotp, ldap3, qrcode (SVG), Jinja2, Bootstrap 5.3 (yerel), FreeRADIUS 3.2, Caddy 2, Docker Compose, pytest, Playwright.

## Global Constraints

- Hedef: tek sunucu, ≈5.000 cihaz; Docker Compose; konteynerler: `caddy`, `freeradius`, `naco`.
- Veritabanı: yalnızca SQLite (WAL, `foreign_keys=ON`, `busy_timeout=5000`).
- Sırlar yalnızca ortamdan: `NACO_MASTER_KEY` (32 bayt, base64/hex), `NACO_INTERNAL_TOKEN` (≥ 32 karakter), opsiyonel `NACO_LDAP_BIND_PASSWORD`, opsiyonel `NACO_ADMIN_PASSWORD`; her biri `<AD>_FILE` ile dosyadan okunabilir. Yer tutucu (`REPLACE_ME…`, `CHANGE_ME…`) → açılış reddi.
- `config.yaml` sır içermez; Pydantic `extra="forbid"`.
- NACo portları: 8080 (panel/API/portal; yalnızca Caddy), 8081 (iç AAA + `/metrics`; yayınlanmaz), 4949 (TACACS+; host 49'a yayınlanır).
- Regex yok; kullanıcı girdisiyle eşleme glob (`fnmatch`) ile.
- bcrypt ve LDAP çağrıları `asyncio.to_thread` ile; event loop asla bloklanmaz.
- Tüm zaman damgaları DB'de UTC; gösterimde `server.timezone`.
- Arayüz dili İngilizce; satır içi script/olay işleyici yok; CDN yok.
- Her commit'te `pytest` yeşil; commit mesajı sonunda `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Push yok (kullanıcı istemedikçe).
