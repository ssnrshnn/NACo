# FreeRADIUS sidecar (802.1X / EAP)

Opinionated FreeRADIUS 3.2 configuration for the default Compose stack. It
terminates the EAP outer tunnel (EAP-TLS / EAP-TTLS / PEAP) and delegates
every identity and policy decision to NACo via the `/api/v1/eap/*` REST
hooks — FreeRADIUS never sees the user database.

## Ports

NACo's built-in RADIUS server owns 1812/1813 (PAP / CHAP / MAB with
Message-Authenticator enforcement); the sidecar listens on **2812/2813**
for 802.1X. Point EAP-enabled switches/SSIDs at 2812, MAB-only gear at 1812.

## Layout

```
raddb/
  clients.conf                # NAS shared secrets ($ENV{NACO_FREERADIUS_SHARED_SECRET})
  mods-available/rest         # rlm_rest → $ENV{NACO_EAP_URL}, bearer $ENV{NACO_EAP_TOKEN}
  mods-available/eap          # outer TLS config, TTLS/PEAP → inner-tunnel
  sites-available/default     # outer server on 2812/2813
  sites-available/inner-tunnel# inner identity → rlm_rest → NACo
certs/                        # generated by quickstart.sh (gitignored)
```

The files are overlay-mounted onto the stock image config
(`mods-enabled/…`, `sites-enabled/…`), so the image's `radiusd.conf` and
default modules keep working.

## Setup

None. `./quickstart.sh` generates the bearer token, the NAS shared secret,
and a self-signed CA + server certificate in `certs/`. Supplicants must
trust `certs/ca.pem` (or skip validation while testing — don't in prod).

## Supported EAP methods

| Method | Status |
|---|---|
| EAP-TTLS + PAP | ✅ recommended — inner password verified by NACo (bcrypt) |
| PEAP + GTC | ✅ same mechanism |
| EAP-TLS | ✅ client certificates signed by `certs/ca.pem` |
| PEAP + MSCHAPv2 | ❌ needs reversible NT hashes; NACo stores bcrypt only |

## Production hardening

* Replace `default-network` in `clients.conf` with per-NAS `client { }`
  blocks bound to specific IPs.
* Replace the quickstart CA with one issued by your PKI (drop
  `server.pem`/`server.key`/`ca.pem` into `certs/` and restart).
* Keep `require_message_authenticator = yes` (BlastRADIUS mitigation).
* Keep `NACO_EAP_URL` on loopback / a private network.

## Config check

```bash
docker compose run --rm freeradius radiusd -XC
```
